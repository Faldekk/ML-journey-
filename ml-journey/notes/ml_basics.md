# Machine Learning Basics

## Supervised Learning
The model learns from labeled data.

### Classification
Predicting categories (e.g., Surviving Titanic).
- Metrics: Accuracy, Precision, Recall, F1-Score.

### Regression
Predicting continuous values (e.g., House Prices).
- Metrics: MAE (Mean Absolute Error), RMSE (Root Mean Squared Error), R2 Score.

## Workflow
1. Data collection
2. Preprocessing (Handling missing values, encoding)
3. Feature selection
4. Model training
5. Model evaluation
6. Persistence (Saving the model)
