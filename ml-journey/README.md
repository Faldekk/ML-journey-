# ML Journey

This is my machine learning journey repository containing beginner ML projects.

## Repository goal
The goal of this repository is to document my learning process and store various implementations of machine learning models, from classification to regression.

## Projects
1. **[01_titanic_survival](01_titanic_survival/)**: Classification project predicting passenger survival.
2. **[02_house_price_prediction](02_house_price_prediction/)**: Regression project predicting housing prices.

## Technologies
- Python
- Pandas & NumPy
- Scikit-learn
- Joblib (for model persistence)
- Matplotlib & Seaborn

## How to run
1. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```
2. Navigate to a specific project folder and run the scripts.

## Learning topics
- Supervised Learning
- Classification vs Regression
- Data Preprocessing
- Model Evaluation (MAE, RMSE, R2, F1-Score)
