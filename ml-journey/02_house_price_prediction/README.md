# House Price Prediction

Regression model to predict housing prices based on various features.

## Files
- `train.py`: Trains the RandomForestRegressor model and saves it.
- `predict.py`: Loads the model and performs prediction on an example from the dataset.
- `data/housing.csv`: Dataset for training and testing.

## How to run
1. Train the model:
   ```bash
   python train.py
   ```
2. Run prediction:
   ```bash
   python predict.py
   ```
